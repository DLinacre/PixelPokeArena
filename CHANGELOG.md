# Changelog

All notable changes to this project are documented here.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-08-21

### Added
- Initial release of the PixelPoke Arena Android app.
- Full-screen WebView wrapper for the live arena.
- Custom pixel-art launcher icon, logo, and banner.
- Dark theme with matching status/navigation bar.
- In-app back navigation and state preservation across rotation.
- Pre-signed release APK for direct sideloading.
- GitHub Actions CI workflow that builds and uploads the APK on every push.
